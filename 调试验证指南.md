### 调试步骤

#### 阶段1：启动调试

```bash
# IDEA中：右键 Main.java → Debug 'Main'
# 或者点击绿色虫子图标
```

**断点1触发**：
```
Thread: main
  at SpringApplication.run(SpringApplication.java:1332)
  at Main.main(Main.java:15)
```

**观察**：
- 调用栈显示从`main()`进入`SpringApplication.run()`
- 变量`primarySource` = `class org.example.springwebflux.Main`

**操作**：按F8（Step Over）或继续

---

**断点2触发**：
```
Thread: main
  at AbstractApplicationContext.refresh(AbstractApplicationContext.java:580)
  at SpringApplication.refresh(SpringApplication.java:754)
  at SpringApplication.run(SpringApplication.java:1354)
```

**观察**：
- 进入`refresh()`方法
- 这里会执行IoC和AOP

**关键变量**：
```java
beanFactory = DefaultListableBeanFactory
beanDefinitionNames = [
  "org.springframework.context.annotation.internalConfigurationAnnotationProcessor",
  "org.springframework.context.annotation.internalAutowiredAnnotationProcessor",
  "main",  // 你的Main类
  "eventBridgeController",  // 你的Controller
  "threadAnalysisController",
  ...
]
```

**操作**：继续（F9）

---

**断点3触发**：
```
Thread: main
  at RequestMappingHandlerMapping.registerHandlerMethod(...)
```

**观察**：
- 正在注册映射
- `mapping` = `{[/users/{id}],methods=[GET]}`
- `handler` = `EventBridgeController`
- `method` = `public Mono waitForData(String)`

**关键代码执行**：
```java
this.mappingLookup.put(mapping, handlerMethod);  // ← 存入映射表
logger.info("Mapped \"" + mapping + "\" onto " + handlerMethod);
```

**操作**：继续（F9），这个断点会触发多次（每个@GetMapping都会触发）

---

**断点4触发**：
```
Thread: main
  at ReactiveWebServerApplicationContext.onRefresh(...)
  at AbstractApplicationContext.refresh(AbstractApplicationContext.java:943)
```

**观察**：
- 调用栈显示：正在`refresh()`中的第9步`onRefresh()`
- 说明IoC、AOP、映射注册都已完成
- 现在准备启动Netty

**关键代码**：
```java
protected void onRefresh() {
    super.onRefresh();
    try {
        createWebServer();  // ← 即将执行
    } catch (Throwable ex) {
        throw new ApplicationContextException("Unable to start reactive web server", ex);
    }
}
```

**操作**：单步进入（F7）`createWebServer()`

---

**断点5触发**：
```
Thread: main
  at NettyReactiveWebServerFactory.getWebServer(...)
  at ReactiveWebServerApplicationContext.createWebServer(...)
```

**观察**：
- 参数`httpHandler` = `HttpWebHandlerAdapter`
- `httpHandler`内部持有`DispatcherHandler`

**关键代码执行**：
```java
// 1. 创建ReactorHttpHandlerAdapter（桥梁）
ReactorHttpHandlerAdapter handlerAdapter = new ReactorHttpHandlerAdapter(httpHandler);

// 2. 注入到Netty
HttpServer serverWithHandler = httpServer.handle(handlerAdapter);

// 3. 创建NettyWebServer
return new NettyWebServer(serverWithHandler, ...);
```

**验证**：
- 展开`handlerAdapter`变量
- 看到`httpHandler`字段 = `HttpWebHandlerAdapter@xxxx`
- 展开`httpHandler`
- 看到`delegate`字段 = `DispatcherHandler@xxxx`
- **证明**：Spring的Handler已注入到Netty的Adapter中！

**操作**：继续（F9）

---

**控制台输出**：
```
INFO ... : Netty started on port(s): 8080
```

**说明**：Netty已启动！

#### 阶段2：验证请求处理

**发送请求**：
```bash
curl http://localhost:8080/event-bridge/status
```

**断点6触发**：
```
Thread: reactor-http-nio-2  ← 注意线程名
  at DispatcherHandler.handle(DispatcherHandler.java:275)
  at HttpWebHandlerAdapter.handle(HttpWebHandlerAdapter.java:87)
  at ReactorHttpHandlerAdapter.apply(ReactorHttpHandlerAdapter.java:76)
  at HttpServerHandler.channelRead(HttpServerHandler.java:245)
```

**观察调用栈**（从下往上）：
1. `HttpServerHandler.channelRead` - Netty接收请求
2. `ReactorHttpHandlerAdapter.apply` - 桥梁转换
3. `HttpWebHandlerAdapter.handle` - 包装为Exchange
4. `DispatcherHandler.handle` - Spring分发

**关键变量**：
```java
exchange = DefaultServerWebExchange {
  request = ReactorServerHttpRequest {  // 包装了Netty的请求
    uri = http://localhost:8080/event-bridge/status
    method = GET
  },
  response = ReactorServerHttpResponse {  // 包装了Netty的响应
    ...
  }
}

handlerMappings = [
  RequestMappingHandlerMapping@xxxx,  // 你的映射表
  ...
]
```

**单步调试**：

1. **F7进入** `mapping.getHandler(exchange)`
   
   ```java
   // 进入RequestMappingHandlerMapping.getHandler()
   // 查找匹配的Handler
   ```

2. **观察**`lookupHandlerMethod()`方法
   
   ```java
   String lookupPath = "/event-bridge/status";
   
   // 从urlLookup查找
   List<T> directPathMatches = this.mappingRegistry.getMappingsByUrl(lookupPath);
   
   // 找到匹配
   Match bestMatch = matches.get(0);
   HandlerMethod handlerMethod = bestMatch.handlerMethod;
   
   // handlerMethod = EventBridgeController#status()
   ```

3. **继续执行**，最终调用你的Controller

**验证成功**：
- ✅ 请求从Netty进入
- ✅ 经过ReactorHttpHandlerAdapter桥梁
- ✅ 进入Spring的DispatcherHandler
- ✅ 查找映射表找到Handler
- ✅ 调用你的Controller方法

## 🔬 详细验证清单

### ✅ 第1步：启动入口

- [ ] 断点触发在`SpringApplication.run()`
- [ ] 调用栈显示从`main()`进入
- [ ] 变量`primarySource`是你的Main类

### ✅ 第2步：容器刷新

- [ ] 断点触发在`AbstractApplicationContext.refresh()`
- [ ] 可以看到`beanFactory`变量
- [ ] `beanDefinitionNames`包含你的Controller

### ✅ 第3步：注册映射

- [ ] 断点触发在`registerHandlerMethod()`
- [ ] `mapping`变量显示URL路径
- [ ] `handler`变量是你的Controller
- [ ] `method`变量是Controller的方法
- [ ] 控制台输出"Mapped ..."日志

### ✅ 第4步：启动Netty

- [ ] 断点触发在`onRefresh()`
- [ ] 调用栈显示在`refresh()`的第9步
- [ ] 即将调用`createWebServer()`

### ✅ 第5步：创建桥梁

- [ ] 断点触发在`getWebServer()`
- [ ] 参数`httpHandler`不为null
- [ ] 创建`ReactorHttpHandlerAdapter`
- [ ] `handlerAdapter`持有`httpHandler`的引用
- [ ] 返回`NettyWebServer`

### ✅ 第6步：请求处理

- [ ] 发送请求后断点触发
- [ ] 线程名是`reactor-http-nio-X`（不是main）
- [ ] 调用栈包含Netty、桥梁、Spring的完整链路
- [ ] `exchange.request.uri`是你请求的URL
- [ ] 最终进入你的Controller方法

## 📝 验证脚本

### 自动化验证脚本

```bash
#!/bin/bash

echo "=== Spring WebFlux 启动验证脚本 ==="

# 1. 启动应用（后台）
echo "步骤1：启动应用..."
mvn spring-boot:run > startup.log 2>&1 &
PID=$!

# 等待启动
sleep 10

# 2. 检查启动日志
echo "步骤2：检查启动日志..."

if grep -q "Spring容器刷新完成" startup.log; then
    echo "✅ 容器刷新完成"
else
    echo "❌ 容器刷新失败"
fi

if grep -q "Mapped" startup.log; then
    echo "✅ 映射表生成成功"
    grep "Mapped" startup.log | head -3
else
    echo "❌ 映射表生成失败"
fi

if grep -q "Netty started" startup.log; then
    echo "✅ Netty启动成功"
    grep "Netty started" startup.log
else
    echo "❌ Netty启动失败"
fi

# 3. 测试请求
echo ""
echo "步骤3：测试请求..."

RESPONSE=$(curl -s http://localhost:8080/event-bridge/status)
if [ $? -eq 0 ]; then
    echo "✅ 请求成功"
    echo "响应: $RESPONSE"
else
    echo "❌ 请求失败"
fi

# 4. 清理
echo ""
echo "清理：关闭应用..."
kill $PID

echo ""
echo "=== 验证完成 ==="
```
