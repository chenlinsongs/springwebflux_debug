# 视频元数据时间修复方案

## 问题总结

- **iOS端元数据**: `creationDate: 2025-11-22T13:36:37+0800` (原始拍摄时间)
- **服务端提取**: `2025-11-22T23:28:40.000+0800` (QuickTime Creation Time，可能是导出时间)
- **时间差异**: 约10小时，且是完全不同的时刻

## 根本原因

iOS在准备上传视频时的处理流程：

```
1. 用户在相册中拍摄视频 (13:36:37)
   ↓
2. 视频存储在相册中，PHAsset.creationDate = 13:36:37
   ↓
3. iOS准备上传，从相册读取视频
   ↓
4. 导出到临时文件 (可能重新编码/转码)  ← 23:28:40
   ↓
5. QuickTime Creation Time 被设置为导出时间 (23:28:40)
   ↓
6. 上传到服务器
   ↓
7. 服务端读取到的是导出时间，不是拍摄时间 ❌
```

## 解决方案（3个选项）

### 方案1: iOS端传递timestamp参数（最推荐）⭐⭐⭐

这是**最可靠**的方案，因为iOS端可以直接从相册获取原始拍摄时间。

#### iOS端代码修改

```swift
// 1. 获取视频资源
func uploadVideo(asset: PHAsset, videoURL: URL) {
    var request = URLRequest(url: URL(string: "http://server/image/upload-video")!)
    request.httpMethod = "POST"
    
    let boundary = UUID().uuidString
    request.setValue("multipart/form-data; boundary=\(boundary)", 
                     forHTTPHeaderField: "Content-Type")
    
    var body = Data()
    
    // 2. 添加视频文件
    body.append("--\(boundary)\r\n")
    body.append("Content-Disposition: form-data; name=\"file\"; filename=\"\(asset.originalFilename)\"\r\n")
    body.append("Content-Type: video/quicktime\r\n\r\n")
    
    let videoData = try! Data(contentsOf: videoURL)
    body.append(videoData)
    body.append("\r\n")
    
    // 3. 添加原始时间戳参数 ← 关键！
    if let creationDate = asset.creationDate {
        let timestamp = Int64(creationDate.timeIntervalSince1970 * 1000) // 转为毫秒
        
        body.append("--\(boundary)\r\n")
        body.append("Content-Disposition: form-data; name=\"timestamp\"\r\n\r\n")
        body.append("\(timestamp)\r\n")
        
        print("📅 视频原始拍摄时间: \(creationDate)")
        print("📅 timestamp参数: \(timestamp)")
    }
    
    body.append("--\(boundary)--\r\n")
    
    request.httpBody = body
    
    // 4. 发起上传
    URLSession.shared.dataTask(with: request) { data, response, error in
        // 处理响应
    }.resume()
}
```

#### 服务端代码修改（修改优先级）

修改 `ImageUploadController.java` 的 `upload-video` 方法：

```java
@PostMapping("/upload-video")
@ResponseBody
public ResponseEntity<Map<String, Object>> uploadVideo(
        @RequestParam("file") MultipartFile file,
        @RequestParam(value = "timestamp", required = false) Long timestamp) {
    
    // ... 文件保存代码 ...
    
    // 修改优先级：客户端时间 > 元数据时间
    Long finalTimestamp = null;
    String timestampSource = null;
    
    // 优先级1: 使用客户端提供的时间戳（iOS从PHAsset.creationDate获取，最准确）
    if (timestamp != null && timestamp > 0) {
        finalTimestamp = timestamp;
        timestampSource = "client";
        
        SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSSZ");
        String formattedTime = sdf.format(new Date(finalTimestamp));
        logger.info("✅ 使用客户端提供的时间戳（最准确）: {}", formattedTime);
    } 
    // 优先级2: 如果客户端没提供，尝试从视频元数据提取
    else {
        Long metadataTimestamp = extractTimestampFromMetadata(file);
        if (metadataTimestamp != null && metadataTimestamp > 0) {
            finalTimestamp = metadataTimestamp;
            timestampSource = "metadata";
            
            SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSSZ");
            String formattedTime = sdf.format(new Date(finalTimestamp));
            logger.info("⚠️  使用从元数据提取的时间戳（可能不准确）: {}", formattedTime);
        }
    }
    
    // 设置文件时间戳
    if (finalTimestamp != null) {
        setFileTimestamp(targetFile, finalTimestamp);
        logger.info("已设置视频文件时间戳: {} -> {}", 
                   originalFilename, new Date(finalTimestamp));
    }
    
    // ... 返回结果 ...
}
```

**优点**：
- ✅ 最准确（直接从相册获取）
- ✅ 不依赖文件元数据
- ✅ 服务端代码已支持，只需修改优先级

**缺点**：
- ❌ 需要修改iOS代码

### 方案2: 打印QuickTime所有元数据，找正确字段

如果不想修改iOS代码，可以尝试从QuickTime元数据中找到正确的时间字段。

#### 服务端代码修改

```java
private Long extractTimestampFromMetadata(MultipartFile file) {
    try (InputStream inputStream = new BufferedInputStream(file.getInputStream())) {
        Metadata metadata = ImageMetadataReader.readMetadata(inputStream);
        
        // 对于视频文件，尝试从 QuickTime 元数据读取
        QuickTimeDirectory quickTime = metadata.getFirstDirectoryOfType(QuickTimeDirectory.class);
        if (quickTime != null) {
            // 调试：打印所有QuickTime元数据
            logger.info("=== QuickTime 元数据详情 ===");
            logger.info("文件名: {}", file.getOriginalFilename());
            
            for (Tag tag : quickTime.getTags()) {
                logger.info("  [Tag {}] {} = {}", 
                           tag.getTagType(), 
                           tag.getTagName(), 
                           tag.getDescription());
            }
            
            // 尝试获取所有可能的时间字段
            logger.info("--- 时间字段检查 ---");
            
            try {
                Date creationTime = quickTime.getDate(QuickTimeDirectory.TAG_CREATION_TIME);
                if (creationTime != null) {
                    SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSSZ");
                    logger.info("  Creation Time: {}", sdf.format(creationTime));
                }
            } catch (Exception e) {
                logger.debug("  Creation Time: 无法获取");
            }
            
            try {
                Date modificationTime = quickTime.getDate(QuickTimeDirectory.TAG_MODIFICATION_TIME);
                if (modificationTime != null) {
                    SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ss.SSSZ");
                    logger.info("  Modification Time: {}", sdf.format(modificationTime));
                }
            } catch (Exception e) {
                logger.debug("  Modification Time: 无法获取");
            }
            
            logger.info("========================");
            
            // 尝试多个时间字段，选择最早的（可能是原始时间）
            Date modificationTime = quickTime.getDate(QuickTimeDirectory.TAG_MODIFICATION_TIME);
            Date creationTime = quickTime.getDate(QuickTimeDirectory.TAG_CREATION_TIME);
            
            // 如果两个时间都存在，选择较早的
            if (modificationTime != null && creationTime != null) {
                Date earlierTime = modificationTime.before(creationTime) ? 
                                   modificationTime : creationTime;
                String timeType = modificationTime.before(creationTime) ? 
                                 "Modification Time" : "Creation Time";
                
                logger.info("✅ 从 QuickTime {} 提取: {} -> {}", 
                           timeType, file.getOriginalFilename(), earlierTime);
                return earlierTime.getTime();
            }
            
            // 如果只有一个时间，使用该时间
            if (modificationTime != null) {
                logger.info("从 QuickTime Modification Time 提取: {} -> {}", 
                           file.getOriginalFilename(), modificationTime);
                return modificationTime.getTime();
            }
            
            if (creationTime != null) {
                logger.info("从 QuickTime Creation Time 提取: {} -> {}", 
                           file.getOriginalFilename(), creationTime);
                return creationTime.getTime();
            }
        }
        
        // ... 其他元数据源 ...
    }
}
```
